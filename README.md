# Exercicios-PP2-React

Exercícios práticos de Paradigmas de Programação II (PP2) desenvolvidos com **React**, **TypeScript** e **Vite**.

## 📌 Conteúdo dos Exercícios (Slides 25 a 30)

1. **Botão Reutilizável (`Botao.tsx`)** - Variantes de estilo (primário/perigo) e manipuladores `onClick` via props.
2. **Contador com Passo (`Contador.tsx`)** - Controle de passo configurável, limite mínimo em zero e botão zerar.
3. **Cartão de Produto (`CartaoProduto.tsx`)** - Renderização de listas com `.map()` e curtidas independentes.
4. **Cartão de Tarefa (`TarefaCard.tsx`)** - Alternância de estado booleano (concluída/pendente) e estilos condicionais.
5. **Conversor de Moeda (`ConversorMoeda.tsx`)** - Input controlado em reais e conversão de moeda.
6. **Enquete (`Enquete.tsx`)** - Contagem de votos, cálculo de liderança em tempo real e botão de zerar.

---

## 🚀 Como executar o projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```
